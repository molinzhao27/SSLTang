# Data contract

Downloader: `python scripts/download_data.py --root RAW --mode train --subject UTS01` (separate `--mode transfer`). Public S3 key discovery is paginated; metadata manifest includes exact keys, sizes, ETags. Dry run supported. Source H5 data are published preprocessing, not raw BOLD; UTS01 84 training story files total20.118GB before excluding the repeated test story wheretheressmoke. S3 ds003020 uses `derivatives`, ds004510 uses `derivative`; GitHub ds003020 tree differs, so S3 discovery governs acquisition.

Preprocess: `python scripts/preprocess.py --root RAW --out TRAIN --mode train --subject UTS01 --block-size 4`; transfer `--mode transfer --out TRANSFER --normalization TRAIN/normalization.npz`. Single subject only per artifact. `manifest.json` contains `runs` with run_id,dataset,subject,condition,session,split,neural_path,n_tr,n_features,tr_seconds,stimulus_path (when available),tr_start_seconds,story,source_key,repeat. Arrays float32 normalized[T,F]. Normalization NPZ stores mean,std,membership,coords,subject,fit_run_ids,n_fit_tr,block_size. Spatial means use nonoverlapping4-voxel cubes (1695 groups for UTS01) in published thick mask. Counts/output dimensions computed from actual mask. Same grouping and train-only mean/std apply unchanged in transfer. SSL uses `split == train` only.

Session split derives actual BIDS session+task names from discovered sidecars; all stories from same acquisition session assigned together. Published derivatives collapse the repeated wheretheressmoke test story; this story is excluded entirely. Fixed-seed whole-session15%val/15%test assignment; no random TR/window splitting. Main should ensure run-local windows.

Timing: published adollshouse H5 has241TR vs respdict261, already20TR trimmed. Reference stimulus code simulates respdict-5, starts10s before story, then slices[10:-5]. Retained stimulus centers are11,13,... seconds. No additional neural trim. Transfer reference decoder simulates centers1,3,... by default, which does not verify reference-clock alignment; our transfer manifest leaves stimulus timing null and uses run-level evaluation; H5 imagined repeats30TR. Condition names exactly `imagined_speech`, `perceived_movie`. Imagined TextGrid is an overt reference transcript rather than observed thought timing; unsuitable for ordinary TR semantic targets. Sintel has no published TextGrid; leave unscored for semantic probes.

Mask: published UTS01 mask_thick has81126 nonzeros, matching training/transfer H5 column count81126. Pycortex convention transposes NIfTI[x,y,z] to[z,y,x] and uses C-order boolean columns. Published decoder applies train-selected voxel indices directly to ds004510 responses, evidence for a shared within-subject column order. H5 contains only `data` and no coordinate metadata, so identity relies on the authors' published derivative/code convention; equal dimension alone is not proof. Never align different subjects by column number.
